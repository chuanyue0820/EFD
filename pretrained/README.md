# Pretrained models

Download the six models from [Google Drive](https://drive.google.com/drive/folders/1tEDt-aw5ZJq2hmuIsvw5HlgEG_ssRIaN?usp=drive_link).
Place the files directly in this directory using the filenames in manifest.json.
The manifest contains SHA-256 hashes of the historical files. If the cloud files
use other filenames, rename local copies to the configured names; do not change
model tensors. Model binaries are intentionally excluded from the Git repository.
